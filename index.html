TRABAJOS REALIZADOS

Mis proyectos

Algunos de los proyectos que he desarrollado durante mi formación académica.

01

Detector de mascarillas

Desarrollé un sistema de detección de mascarillas utilizando un modelo de inteligencia artificial entrenado con aproximadamente 7500 imágenes de personas con y sin mascarilla. Implementé la detección mediante una cámara en tiempo real.

Python OpenCV TensorFlow
02

Detección y conteo de personas

Implementé un sistema de detección de personas en videos utilizando YOLO. Trabajé con áreas delimitadas para identificar y contar personas dentro de una zona específica.

Python YOLO OpenCV
03

Sistema de gestión de estudiantes

Desarrollé una aplicación de escritorio que permite registrar, consultar, modificar y eliminar información de estudiantes. Implementé una interfaz gráfica y conexión con una base de datos.

Java MySQL Swing
04

Botica Nova Salud

Proyecto académico orientado al desarrollo de un software web para gestionar productos, controlar el inventario y administrar las ventas de una botica, facilitando la organización de sus operaciones.

Desarrollo web Frontend Backend
05

ECOLIM - Gestión de residuos

Diseñé en equipo una aplicación móvil para operarios encargados de la recolección de residuos. Incluye inicio de sesión, consulta de rutas asignadas, registro de recolecciones, historial editable y reportes con indicadores y gráficos.

Aplicación móvil Gestión de residuos Reportes y gráficos
